# 三点水 (San Dian Shui) - UI/UX Portfolio

A clean, premium personal portfolio website showcasing professional design projects. Built with React 18, Tailwind CSS, and Lucide icons.

## Pages
- Home (`index.html`)
- Works (`works.html`)
- Project Detail (`project.html`)
- About (`about.html`)

## Design System
- Minimalist, Apple-inspired editorial layout.
- Soft neutral colors, clean grid system, and elegant typography.
- Responsive design for desktop and tablet.
